# Application Screenshots Overview

1. **`01_home_dashboard.png`**: Landing page featuring hero banner, live ML statistics, and 5-stage pipeline diagram.
2. **`02_loan_application_form.png`**: Interactive loan evaluation form with preset quick-loader buttons and real-time validation.

5. **`05_analytics_model_comparison.png`**: Interactive model benchmark comparison chart across 7 Machine Learning algorithms.
6. **`06_feature_importance_eda.png`**: Bar chart visualization of feature weights and confusion matrix breakdown grid.
